# Memoria V3

Cambios principales:
- Nueva pantalla de inicio.
- Selector de niveles accesible desde el inicio y al terminar una partida.
- Filtros: Todos, Sin estrellas, Por mejorar y 3 estrellas.
- Se conserva el progreso de V2 cuando existe en el mismo navegador.
- Fotografías reales organizadas por conceptos claramente distintos (gato, perro, avión, guitarra, balón, etc.).
- Cada pareja se construye a partir de un ID de concepto y aparece exactamente dos veces.
- La dificultad aumenta por cantidad de parejas, no por usar fotografías visualmente ambiguas.
- Usar una pista limita esa partida a un máximo de 2 estrellas.
- Se mantienen récords, rachas, memoria perfecta y retos para amigos.
- Las fotos se cargan desde LoremFlickr y quedan en caché después de usarse; la primera carga requiere conexión.
